# nuxt-ddd-toolkit

DDD toolkit for Nuxt and Nitro projects, with optional integration for `nuxt-laravelize`.

## Current bootstrap scope

- capability detection for `nuxt-laravelize`
- `laravelize` CLI entrypoint (`laravelize` and `lz`)
- runtime capability composable
- module and playground aligned with `nuxt-ddd-toolkit`

## Local development

```bash
pnpm install
pnpm dev:prepare
pnpm dev
```

## Quality checks

```bash
pnpm lint
pnpm test
pnpm typecheck
```
